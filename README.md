# esp32-to-gps

> [!CAUTION]
> **AI in use, use at own risk.**

An **ESP32-C3 SuperMini** running Tasmota, wired to a **GPS receiver**. The
aim is for it to publish everything the receiver knows (position, satellites,
signal quality, time) to Home Assistant over MQTT, and to feed the receiver a
correction stream from an NTRIP proxy on the local network.

This is a sibling of [esp32-to-433mhz](https://github.com/mithro/esp32-to-433mhz)
and follows its layout.

## Wiring

Every receiver uses the same pins on the SuperMini's right-hand header:
**GPIO4** transmits to the receiver, **GPIO3** receives from it and **GPIO1**
takes its PPS pulse.

![SuperMini pin assignment](docs/images/pinout-supermini-gps.svg)

[docs/wiring.md](docs/wiring.md) has a diagram and a wire table for each
receiver. Two of them need care:

* The **LC29H** takes 5 V and needs a two-resistor divider on its RX pad.
* The **LEA-M8T** card takes 3.3 V only, and its connector has to be checked
  with a meter before it is powered.

## Regenerating the drawings

The drawings are generated by the scripts in `scripts/`, which need only
[uv](https://docs.astral.sh/uv/):

```
uv run scripts/draw_pinout.py
uv run scripts/draw_wiring.py
```
